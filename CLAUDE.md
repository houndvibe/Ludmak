# Людьмак — заметки для Claude

## Игра

Людьмак — монстр-ведьмак, берёт заказы от нечисти на людей. Забег — 5 ночей.

- **Ночь — дом Людьмака** (центральный экран). Уровень Людьмака = лимит заказов за ночь (LEVEL_BY_NIGHT: 1, 2, 3, 3, 4). Монстры по одному подходят к окошку в двери, их уровень + QUEUE_EXTRA. Каждого можно принять или отклонить (принял — на лист заказа падает печать `HomeScene.stampCard`: сначала капля воска `ui/seal_wax.png`, потом оттиск с «Ъ» `ui/seal_imprint.png`, место `HOME_LAYOUT.stamp`, анимация `FEEL.stamp`, звук `seal_stamp`). Как только лимит набран, очередь сразу заканчивается (окошко закрывается). **Квесты:** у каждого заказчика 5 (`ClientDef.quests` в clients.ts: реплика + подходящие модификаторы), за забег не повторяются (`run.usedQuests`, `Contract.quest`; показанный у окошка — использован, даже отклонённый); модификатор врага выпадает с обычным шансом, но из `mods` квеста. Пока очередь не закончилась, закрыта только дверь: в магазин и к сумкам можно сходить между посетителями (по возвращении у окошка тот же монстр). Потом: сундук → магазин (5 случайных предметов; купить — перетащить товар в «Твои вещи», продать — свою вещь к товарам), сумки → укладка рюкзака на сетке, дверь → «На охоту» (или «Переждать день», если заказов нет — сразу к итогам).
- **День:** автобатлер. Враги всех принятых заказов идут одной цепочкой, по одному. На экране боя обе сетки: слева рюкзак героя (как собран ночью), справа сумка врага (фиксированная раскладка из данных, соседство не считается). Пассивные предметы героя срабатывают сами по перезарядке; активные применяются нажатием на предмет в рюкзаке. **Расходники тратятся навсегда:** заряды хранятся на предмете, кончились — предмет исчезает из рюкзака. Хлеб — пассивный расходник: каждое срабатывание тратит заряд. Враг использует предметы по priority, раскладка на порядок не влияет (снаряды с зарядами, потом основное оружие; щит по перезарядке; мешок при ударе). Внутри заказа следующий враг выходит сам, без подтверждения; следующие враги заказа видны колодой карт за портретом текущего (`FEEL.enemyDeck`), новый выезжает из колоды. Отступить можно только на привале между заказами — это заканчивает день, неустойка за каждый незавершённый заказ. Здоровье героя за день не восстанавливается: ни между врагами, ни на привале между заказами (привал — только пауза «Дальше / Отступить»). Полное здоровье — в начале каждого дня.
- **Рюкзак — сердце игры.** Соседство (касание стороной клетки) по тегам: правила — данные `src/data/synergies.ts`, числа — `SYNERGY` в balance.ts, расчёт — `src/systems/synergy.ts` (`computePower`). Только у героя. Проценты к характеристике складываются, отключение сильнее бонусов, отключённый предмет ни на кого не влияет. В рюкзаке: метки при перетаскивании, пергамент справа: «Сила снаряжения» или наведённый предмет (одинарный клик по предмету закрепляет его описание — `pinnedItem`; клик мимо — открепить) — числа значками (`itemStatChips`), полные фразы в подсказке при наведении на значок (`BackpackScene.showPanel`); в бою подсказка предмета — текстом «база / итог / от кого», полоски связей на общих сторонах (`pairLinks` в synergy.ts → `GridView.setLinks`; яркие с цепью при наведении и перетаскивании, в бою — тонкие). В бою пересчитывается на лету, когда предмет исчезает. **Слияние** такого же предмета того же уровня: ★2 / ★3 (`STAR_MULT`), в рюкзаке и при покупке. Пока предмет держат над таким же — превью результата: в рюкзаке пергамент показывает цель после слияния «было → станет» с учётом соседей (`BackpackScene.drawMergePanel`, `mergedPreview` в state.ts, колбэк `onMergeHover` в GridView), на соседях — метки, что у них изменится (`mergeLabels`, `chipsDiff` в ui.ts); в магазине — плашки-значки у низа мешка вместо надписи: предмет ★N, цена, «было → станет» (без соседей). В магазине свою вещь можно слить с такой же прямо в мешке (перетащить плитку на плитку, `ownedMergeTile`). Значки сравниваются по иконке, тегу и порядку (`matchChips` в ui.ts — у щита два значка-щита). Звезда усиливает главный эффект каждого предмета (`starStats`): урон, лечение, блок, оглушение, заряды, прибавку множителя масла, а у амулетов — силу ауры (`starAura`, в `computePower` и `auraInfo` / `auraText`); явные числа ★2/★3 для подковы, камня, ладанки, мандрагоры, масла и бомбы — `STAR_LEVELS` в balance.ts, остальное — база × `STAR_MULT`; перезарядка, длительность и самоурон не меняются.
- **Парирование:** атака врага (предмет с уроном) идёт через окно — `BattleSim.pending` (замах `windup` → удар `strike`), окно в реальном времени `FEEL.parry.window` (`step(dt, realDt)`), `BattleSim.parry(id)` — урон ×`PARRY_DAMAGE_MULT`, мешок не крадёт. Смерть врага отменяет удары в полёте. Атака летит из глубины: в случайной точке `parryZone` растёт на месте с ускорением и крутится, вокруг стягивается золотое кольцо (картинка — предмет врага, которым он бьёт; `BATTLE_LAYOUT.parryIconOverride` = null) от `FEEL.parry.startScale` до полного размера (полный — удар); зона клика — всё внутри кольца (с лёгкой заливкой `FEEL.parry.ringFillAlpha`), ранний клик не наказывается. **Основное оружие** (`run.mainUid`; стартовый меч — сразу основной): выбирается в сумках двойным кликом по оружию или щиту или перетаскиванием на поле «Основное» (`GridView` `dropZone`; клик ничего не поднимает: перетаскивание — после сдвига мыши на `FEEL.dragThreshold`) (`onDoubleClick` в GridView, `setMain` в state.ts), видно в поле слева от верхнего ряда сумок (`BACKPACK_LAYOUT.mainSlot`); снять основное нельзя — только сменить; основным может быть только предмет в сумках (`canBeMain`), убранное вне сумок перестаёт быть основным; основное не продаётся — потерять его можно только в бою и меткой-клинками на предмете; основное остаётся в сетке и работает как обычно. В бою курсор — картинка основного (`UI_ART.cursorWeapons`: tip на курсоре, вращается вокруг grip; отбивает отрезок tip → bladeEnd — меч весь клинок, кинжал клинок, факел вся длина, топор лезвие; щит — `cursorShield`, вся область). Нет основного или оно отключено (`BattleSim.mainSlot`) — парировать нельзя, плашка «Нечем отбивать». Перки (`ItemDef.parryPerk`, числа `PARRY_PERK`, `BattleSim.parryPerk`): меч — базовые 50%; щит — гасит 80%; кинжал — бьёт врага половиной своего урона (`daggerMult`); факел — +0.2 с к перезарядке всех предметов врага до конца боя с ним (до +1 с, `EnemyState.torchSlow`); топор — заряд за парирование (весь день, `axeCharges`, в финальный бой — `run.axeCharges`; пропущенная атака сжигает заряды), на 4 следующий удар топора ×2; серп — лечит на 3. Значки перков — `parry` + значок эффекта (`StatChip.icon2`). парирование — правой кнопкой мыши (клинок прокручивается на 360° вокруг рукояти с шлейфом), левая кнопка ничего не делает; парировал — искры, предмет отбит вправо; не успел — предмет долетает до портрета героя. **Щит-курсор:** предмет с `parryShield` (деревянный щит) в рюкзаке и не отключён (`BattleSim.shieldStar`) — курсор в зоне атак становится картинкой щита (`FEEL.parry.shieldSize`), парирует круг щита (`UI_ART.cursorShield.hitShare`), клик — толчок; медлительность — пассивные предметы героя с уроном бьют реже: к перезарядке +1 / 0.7 / 0.5 с по уровню щита (`SHIELD_SLOW_BY_STAR`), от нескольких щитов складывается (`shieldSlow` в synergy.ts, считается в `computePower`); оружие, касающееся щита, получает от него только `SYNERGY.shieldCover` (60%) медлительности — правило `shield_cover`; в бою — плашка-тег дебафа под здоровьем героя (значок `slow`, `BattleScene.syncDebuffs`, `BattleSim.slowSec`), на карточке щита — значок медлительности; блок 5 / 8 / 11 раз в 4 с на ★1 / ★2 / ★3 (`STAR_LEVELS`). Пока у героя или врага есть блок, его полоска здоровья в жёлтой рамке, рядом значок щита с числом (`FEEL.blockMark`, `BattleScene.setBlockMark`). Баланс — на 60% парирований (`BALANCE_PARRY_RATE`: бот симуляции парирует столько в основных таблицах; отдельная таблица 0/30/60/100%; со щитом-курсором бот парирует чаще на `SHIELD_PARRY_BONUS` — оценка, своя таблица «Щит-курсор»: щит ★1/★2/★3 при прибавке 0 / 0.1 / 0.2).
- **Рисунки атак врагов** (паттерн — у предмета: `EnemyItemDef.pattern`, особенность — у врага: `ritual` / `escape` / `quen` в enemies.ts; числа — `ENEMY_ITEM_STATS`, `ENEMY_PATTERN`, окна и отрисовка — `FEEL.patterns`, `FEEL.stain`, `FEEL.quen`). Кружок в бою — `PendingAttack` с `kind` (`AttackKind`: hit, thrust, guard, sack, escape, cross, burst, aim, reflect), `delay` (серия, прицел, мешок), `group` (серия), `partner`/`locked` (пара кистень + мешок: отбил один — второй нельзя), `from` (щит стражника в конце выпада). Любой кружок — атака (перки, Безголовый, топор); один клик — один кружок. Крестьянин — пропущенная лепёшка оставляет пятно (`BattleScene.stain`). Стражник — щит ×0.25 к урону героя, пока не сбит (`guardMult`, `EnemyState.guardBroken`); копьё — двойной удар на концах жёлтого отрезка (`double`), отбил оба — кружок щита на отрезке, отбил и его — щит опущен. Разбойник — мешок к каждому удару кистеня, крадёт из кошелька (`BattleConfig.coins`, `BattleSim.wallet`, событие `steal` — сцена сразу меняет `run.coins`), убил — возврат (`refund`), ниже `escapeBelow` — кружок бегства. Монах — крест из 4 ударов, ритуал (пропущен хоть один удар — следующая вода освящена ×`blessMult`, `afterRitual`). Аристократ — очередь внахлёст, пистоль с прицелом (событие `aim`). Ведьмак — выпад/крест/очередь на своём оружии, Квен, бомба назад (`reflect`, `heroStun`). Бот симуляции парирует по `PARRY_RATE_BY_KIND`. У Безголового нет разбойников (`ClientCondition.noEnemies`).
- **Ведьмак — финальный босс, не заказ** (`FINAL_BOSS` в balance.ts). В начале ночи 1 — письмо «Доброжелателя» (`WITCHER_LETTER` в `src/data/story.ts`, `HomeScene.showLetter`, `run.letterRead`, раскладка `HOME_LAYOUT.letter`), В ночь 5 после итогов дня («Ведьмак →» в Results, `finalAhead`) — бой с ним (`BattleScene` с `{ final: true }`, `finalChain`) со здоровьем после дня (`DayOutcome.heroHp` → `run.finalHp`; погиб днём или переждал — полное). Победа — игра не заканчивается экраном: Людьмак дома (`run.finished`), окошко и дверь закрыты, заказов нет, на месте карточки — записка с благодарностью (`THANKS_NOTE` в story.ts, `HomeScene.showEpilogue`, кнопка «В меню»); поражение — −1 жизнь и бой заново с полным здоровьем, пока есть жизни (`resolveFinal`); награды и неустойки нет. Ведьмак уклоняется от первой бомбы (`dodgeFirstBomb`). Сумка 3×5 — предметы героя в руках ведьмака (`EnemyItemDef.art`: имя и картинка героя, числа вражеские): стальной меч, серебряный меч (свой), два серебряных кинжала, серебряная подкова в центре (касается всех четырёх клинков), бомба «Гром», лечебный эликсир. Оружие бьёт параллельно, каждое по своей перезарядке (`parallelWeapons` у врага → `EnemySlot.own`); подкова — аура врага (`auraBoost`, режим `aura`, `applyEnemyAuras` в battle.ts: соседи по стороне +25% к урону и лечению, `EnemySlot.boost`).
- **Условия заказчиков** (`src/data/clients.ts`, числа — `CLIENT_REWARD_MULT`, `CLIENT_PENALTY_MULT`, `GHOST_FIRST_HIT_MULT`) действуют только в бою с врагами своего заказа. Запрет предмета — внешнее отключение в `computePower(items, blocked)`: предмет серый и ни на кого не влияет, пересчёт идёт при смене врага. Упырь запрещает отступать, пока его заказ впереди (`BattleSim.retreatBlockedBy`). Кикимора: аванс — награда при принятии (`decideVisitor`), провал — вернуть аванс (`ContractResult.refund`) и неустойка ×2. Безголовый (`parryReward`): отбил ≥ `PARRY_REWARD_SHARE` атак врагов его заказа — награда ×`PARRY_REWARD_MULT` (счёт — `BattleSim.attacks` / `parried`, итог — `DayOutcome.parryGoals`, в бою счётчик на плашке условия). Видно на карточке, на доске и плашкой в бою.
- **Значки вместо слов:** карточка заказа, доска «Заказы на сегодня» и окно врага показывают числа и условия плашками-значками, полная фраза — в подсказке при наведении (`addChips`, `withHoverTip`, `conditionChips`, `enemyItemChips` в ui.ts; новые значки — StatIconId в assets.ts, рисунки — glyphs.ts). Награда и неустойка: слово обычным цветом, монета, число зелёное или красное. Модификатор врага — кружок с буквой перед именем, в окне врага — плашка-тег.
- **Модификаторы врагов** (`src/data/modifiers.ts`, числа — `MODIFIER_STATS`, шанс — `MODIFIER_CHANCE_BY_NIGHT`) выпадают при генерации заказа: `Contract.mods` параллельно `enemies`, `ChainLink.mod`. Не больше одного на врага, у босса нет. Приставка к имени (`enemyName`), значок на портрете в бою.
- **Магазин по ночам:** редкость `tier` 1–3 у предмета, веса `SHOP_TIER_WEIGHTS_BY_NIGHT`, выбор — `src/systems/shop.ts`. С ночи 2 одно место — всегда расходник (`SHOP_CONSUMABLE_FROM_NIGHT`). Экран — лавка нечисти под сундуком (`SHOP_LAYOUT` в assets.ts, фон `backgrounds/shop.webp`, без него — заглушка): слева прилавок, карточки 3 + 2 уменьшены до `cards.scale`, под ним «Обновить ассортимент»; посередине торговец (только на фоне); справа мешок «Твои вещи» — плитки 3 в ряд постранично, под ним «Домой →». Карточка товара — картинка `UI_ART.shopCard` (plain — обычный, rare — редкий/особый; раскладка внутри под нарисованные ячейки там же; без картинки — рамка по редкости). Наведение на карточку и плитку своей вещи — приподнимается с золотой обводкой; при перетаскивании за курсором едет картинка предмета, зона покупки/продажи подсвечивается сильнее, когда предмет над ней, плитка для слияния — зелёным (`FEEL.shop`).
- **Итоги и жизни:** долга больше нет. Награды и неустойки → монеты (не уходят в минус). У героя 2 жизни на забег (`START_LIVES`, `run.lives`, сердечки в шапке — `addCoinsAndLives` / `addLives` в ui.ts, картинки сердец и монеты — `UI_ART.icons`, без картинок — текст `livesText`). Смерть в бою: −1 жизнь, случайный предмет, полная неустойка; жизней 0 — конец игры. Пережил 5-ю ночь — победа. Продажа: половина суммарной стоимости × доля оставшихся зарядов. Все деньги поделены (цены ÷2, награды ÷4).
- **Бой детерминирован.** Случайность — только в отдельных предметах (самоурон топора, взрыв шумного от огня) и в модификаторе «Пьяный» (промахи). Глобальную случайность не добавлять.
- **Смерть в бою:** −1 жизнь, полная неустойка за незавершённые заказы + потеря случайного предмета; вторая смерть заканчивает забег.
- **Обучение** — сценарий ночи 1 (`src/data/tutorial.ts`): только леший без «Отказать», фиксированный магазин из 4 предметов без обновления, 22 шага строго по порядку (`TUTORIAL_STEPS`; первые четыре — части листа заказа: шапка и текст, условие, враги, деньги — `HomeScene.cardAreas`, номер — `run.tutorialStep`): всё, кроме нужного элемента, затемнено и заблокировано, стрелка и попап (`components/Hints.ts`: сцена в create вызывает `tutorialAttach(scene, resolve)` — resolve(шаг) отдаёт прямоугольник элемента (с `drop` — второе светлое окно, куда тащить), 'skip' или null; после действия — `tutorialDone`, при смене состояния — `tutorialRefresh`; бой на паузе, пока `tutorialBlocking`). Флаг «пройдено» — `localStorage` (`isTutorialDone` / `markTutorialDone` в state.ts, всё в try/catch), ставится на итогах ночи 1. В меню «Пропустить обучение» — пока не пройдено (на время разработки `TUTORIAL_ALWAYS = true`: обучение всегда и кнопка всегда видна).
- **Debug-режим** — галочка в меню (`ludmak.debug` в localStorage), `newRun(tutorial, debug)` → `run.debug`: без обучения, `DEBUG_COINS` монет, в магазине все предметы (`rollShop`), товар не кончается (`buy`, `buyAndMerge`), обновления нет (`canReroll`); товары листаются страницами по `SHOP_SIZE` в ShopScene.
- **Ощущения** (`src/config/feel.ts`): цвета цифр по типу, крупные большие удары, тряска на сильных ударах по герою и взрывах, стоп-кадр при смерти врага, баннеры, затемнение между сценами; переход на бой — наезд камеры на дверь дома и вступление боя (отъезд камеры, портреты въезжают с боков, надпись «Ночь N — охота»; бой стоит, пока идёт) — `FEEL.battleIntro`. Переход между сценами — только `goto(scene, key, data)` из ui.ts; первой строкой `create()` — `fadeIn(this)`.
- **Звук** (`src/config/audio.ts` — ключи, `src/config/volume.ts` — громкость каждого звука, `components/Sound.ts` — `sfx`, `playMusic`; кнопки «Без звука» в шапке нет, громкость — ползунок в меню): файлы `public/assets/audio/{key}.ogg`, запасной `.mp3`, грузит Boot; нет файла — тишина и строка `[audio]` в консоли. Новый звук — ключ в `SOUND_KEYS` и вызов `sfx(scene, key)` в месте события.

Полный диздок: `docs/designdoc.md`. Роли: пользователь — геймдизайнер (дизайн и баланс), код пишет Claude, арт рисует художница.

## Стек

Phaser 3 + TypeScript + Vite, веб-билд для itch.io. Scale FIT, базовое разрешение 1920×1080. Шрифты: PT Serif — текст (`FONT`), Kurale — заголовки, имена, кнопки (`TITLE` в ui.ts, без жирного); файлы — `FONT_FILES` в assets.ts, грузит main.ts до старта игры.
Команды: `npm run dev`, `npm run build` (tsc + vite build → `dist/`), `npm run typecheck`, `npm run sim` (симуляция боёв без графики: собирается `vite build --ssr` в `.sim/` и запускается node — без новых зависимостей).

Логика в `src/systems/` и `src/config/`, `src/data/` не должна импортировать Phaser — иначе сломается `npm run sim`. Phaser — только в сценах, `ui.ts`, `components/` и `state.ts`.

## Структура

```
src/
  main.ts            — конфиг Phaser, список сцен
  state.ts           — состояние забега: монеты, предметы, очередь у двери, принятые заказы, магазин, итоги дня,
                       флаг обучения (run.tutorial, показанные подсказки, «пройдено» в localStorage)
  ui.ts              — кнопки (со звуками клика и наведения), текст, шапка, подписи предметов,
                       всплывающая сумка врага (components/EnemyTooltip.ts: портрет и сумка, ширина по содержимому; наведение на предмет — карточка предмета на картинке обычной карточки магазина сбоку, `ENEMY_TOOLTIP_LAYOUT.card`), переходы goto / fadeIn
  config/balance.ts  — ВСЕ числа баланса (в т.ч. предметов врагов и правила их использования)
  config/feel.ts     — ощущения: длительности, размеры, пороги, цвета цифр (не баланс)
  config/audio.ts    — манифест звуков и музыки (ключи), лимит копий, смена музыки
  config/volume.ts   — громкость: общая (звуки, музыка) и каждого звука и мелодии отдельно
  config/assets.ts   — манифест ассетов (ключ → путь, заглушки) и раскладки экранов: HOME_LAYOUT (под home.png),
                       BACKPACK_LAYOUT, BATTLE_LAYOUT, HINT_LAYOUT, HEADER_LAYOUT, MENU_LAYOUT;
                       UI_ART — оформление художницы (кнопки, шапка, сердца, монета, пергамент карточки заказа), необязательное;
                       MENU_ART — главное меню по макету художницы (фон backgrounds/menu.webp, логотип, рамка кнопок, ползунок громкости); живой фон меню — моргающие глаза в лесу (MENU_ART.eyes, вырезаны из варианта фона), осколки печати парят вокруг своих мест (MENU_ART.shards — вырезаны из логотипа, логотип без них — logo_clean.png) и свечение за печатью, лучи и свет над тропой (FEEL.menuLife, MenuScene.addAmbience / addSealLife)
  data/*.ts          — предметы героя (с редкостью tier), предметы врагов, враги (размер и раскладка сумки),
                       заказчики (реплики и условия), теги, modifiers.ts — модификаторы врагов,
                       tutorial.ts — сценарий обучающей ночи и тексты подсказок,
                       synergies.ts — правила соседства (одна запись = одно правило) — без чисел
  components/GridView.ts — ОДИН компонент сетки с предметами для всех мест; режимы 'edit' (экран рюкзака: перетаскивание,
                       метки соседства, слияние, страницы «вне сумок»), 'battle' (рюкзак героя в бою, клик применяет), 'view' (сумка врага)
  components/Hints.ts  — обучение: затемнение всего, кроме нужного элемента, стрелка, попап, блокировка остального
  components/PortraitLife.ts — живой портрет (Phaser Rope): дыхание, покачивание, свет глаз, светлячки; какие портреты —
                       PORTRAIT_LIFE в assets.ts, движение — FEEL.portraitLife (сейчас только леший в окошке дома)
  components/Sound.ts  — звуки (sfx с лимитом копий), музыка с плавной сменой, «Без звука»
  systems/backpack.ts  — логика сеток: маски, поворот, проверка размещения (общая для героя и врагов)
  systems/synergy.ts   — соседство и уровень ★: итоговые характеристики, эффекты с источниками, «сила снаряжения»
  systems/contracts.ts — уровень по ночам, генерация очереди монстров с заказами (множители заказчика, модификаторы врагов)
  systems/shop.ts      — ассортимент магазина по ночам (редкость по весам ночи)
  systems/battle.ts    — ВСЯ логика боя (BattleSim) без Phaser: сцена боя только рисует её события;
                       характеристики предметов героя берёт из computePower и пересчитывает при исчезновении предмета
                       и при смене врага (условие его заказа, модификатор); модификаторы, уклонение ведьмака
  systems/random.ts    — случайность без Phaser (для боя, заказов и симуляции)
  data/story.ts        — письмо о ведьмаке (ночь 1) и записка-благодарность
  sim/simulate.ts      — симуляция баланса (npm run sim): ночь 5 — день и затем ведьмак (со здоровьем после дня и с полным),
                       шанс пройти забег — победить ведьмака, пока есть жизни; ночь 1 (меч и покупки ночи 1), эталонные сборки REF по ночам
                       (осмысленная — с позициями под соседство; наивная — те же предметы, случайная раскладка),
                       бой по ночам, экономика (доход, восполнение расходников, бюджет сборки), шанс пройти забег (меньше START_LIVES смертей), таблицы
                       влияния каждого условия заказчика и каждого модификатора; альтернативные сборки (щит, масло, мандрагора,
                       проклятие), бот-игрок (неполный набор заказов, отступление на привале), «откуда урон» (по типам врагов,
                       здоровье на привалах). Цели баланса — в designdoc, «Баланс»
  scenes/            — Boot, Menu, Home, Shop, Backpack, Battle, Results, GameOver
public/assets/       — арт художницы (PNG) и звуки (audio/*.ogg), см. README
docs/                — дизайн-документ
```

Переходы: Boot → Menu → Home ⇄ Shop / Backpack → (дверь) Battle или Results → Results → Home следующей ночи или GameOver.

## Правила

- Данные игры — только в `src/data/*.ts`.
- Числа баланса — только в `src/config/balance.ts`, с комментарием, что число значит. Длительности, размеры и пороги эффектов — в `src/config/feel.ts`, звука — в `src/config/audio.ts`, громкость — в `src/config/volume.ts`.
- Картинки — только через ключи из `src/config/assets.ts`. Сцены не обращаются к файлам напрямую. Отсутствующий файл → заглушка в Boot под тем же ключом. Координаты элементов дома — в `HOME_LAYOUT`, не в коде сцены. Портрет в окошке обрезается скруглённым прямоугольником `HOME_LAYOUT.window` или маской проёма с фона (`HOME_LAYOUT.windowMask`, сейчас null; для варианта фона backgrounds/home_v2.webp готова ui/home_window_mask.png).
- Новые зависимости (кроме phaser, typescript, vite) — только с согласия пользователя.
- Делать только то, что попросили на текущий этап; не добавлять фичи и абстракции сверх задачи.
- Не удалять существующие файлы без подтверждения.
- **Не делать git commit** — коммиты делает пользователь сам, даже если в задаче написано «коммить после этапа».
