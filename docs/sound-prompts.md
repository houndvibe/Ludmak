# Людьмак — промпты ElevenLabs для каждого звука

Один промпт — один звук. В каждом указаны итоговый файл и длительность.
Готовый файл кладётся в `public/assets/audio/` под этим именем (если ElevenLabs отдал mp3 — то же имя с `.mp3`).
Длительность ставь и в поле Duration. Если меньше 0,5 с задать нельзя — сгенерируй 0,5 с и обрежь в редакторе.
