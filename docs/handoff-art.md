# Передача: арт и интерфейс (Соня → Артём)

Проект проверен: `tsc --noEmit` без ошибок. Игровая логика, баланс и данные не менялись — только оформление, ассеты и раскладки.

## Как запустить на Windows

1. `node_modules` из этой папки не использовать — там пакеты под Mac. Удалить папку `node_modules` (или не копировать её вовсе) и выполнить `npm install`.
2. `npm run dev` — проверить игру, `npm run build` — сборка.
3. Перед коммитом:
   - `art_sources/` (≈126 МБ) — исходники и оригиналы Сони, в игру не идут. Лучше добавить в `.gitignore` и не коммитить.
   - `.DS_Store` (служебные файлы macOS, 7 штук) — тоже в `.gitignore`.
   - `public/assets/backgrounds/home_sketch_3.png` (4,4 МБ) — исходник фона дома, игра берёт `.jpg`. Можно перенести в `art_sources/`, иначе он попадёт в сборку.
