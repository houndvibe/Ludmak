# Людьмак

Рогалик с рюкзаком-головоломкой и автобатлером для геймджема. Phaser 3 + TypeScript + Vite.
Дизайн-документ: [docs/designdoc.md](docs/designdoc.md).

**Цикл ночи:** дом Людьмака. Монстры по одному подходят к окошку в двери, каждого можно принять или отклонить. Уровень Людьмака — это сколько заказов можно принять за ночь: 1, 2, 3, 3, 4 по ночам. Монстров приходит на два больше уровня. Как только набран лимит, окошко закрывается. Потом открываются сундук (магазин), сумки (рюкзак) и дверь. Днём все принятые заказы идут одной цепочкой врагов, между заказами — привал (пауза, здоровье не восстанавливается). Потом итоги и платёж по долгу, следующая ночь снова начинается дома.

**Бой:** слева Людьмак и его рюкзак (та же сетка, что собрана ночью), справа враг и его сумка. Пассивные предметы срабатывают сами, их перезарядка видна прямо на иконке. Активные предметы применяются нажатием на них в рюкзаке. Расходники тратятся навсегда: когда заряды кончились, предмет исчезает из рюкзака. Размер клеток и расположение элементов боя задаёт `BATTLE_LAYOUT` в `src/config/assets.ts`.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev
```

Игра откроется на http://localhost:5173. Проверка типов без сборки: `npm run typecheck`.

## Симуляция баланса

```bash
npm run sim
```

Прогоняет бои без графики, по 500 раз на вариант, и печатает процент побед, медианное и минимальное оставшееся здоровье героя:
- ночь 1 со стартовым мечом и с мечом плюс каждый предмет, который можно купить в ночь 1;
- ночи 1–5 с полным набором заказов по уровню для эталонных сборок `REF` (в `src/sim/simulate.ts`): «осмысленная» разложена под соседство, «наивная» — те же предметы в случайной раскладке;
- экономику по ночам: доход, платёж, восполнение расходников, бюджет сборки, доход при половине заказов;
- влияние каждого условия заказчика и каждого модификатора врага.

Симуляция гоняет ту же логику боя, что и игра (`src/systems/battle.ts`), и берёт числа из `src/config/balance.ts`. Поправили баланс — запустите ещё раз. Бот лечится, когда лечение не уйдёт впустую; бомбу, масло и мандрагору применяет по одному заряду на врага. Цели баланса и итоговые цифры — в дизайн-документе, раздел «Баланс — ключевые числа».

## Билд для itch.io

```bash
npm run build
```

Готовая игра появится в папке `dist/` (`index.html` в корне, пути относительные). Упакуйте **содержимое** `dist/` в zip, не саму папку:

```powershell
Compress-Archive -Path dist\* -DestinationPath ludmak.zip -Force
```

На itch.io: Kind of project — **HTML**, загрузить zip, отметить «This file will be played in the browser». Размер окна — 1920×1080 или 1280×720 (игра сама масштабируется), включите кнопку Fullscreen.

Проверить билд локально: `npm run preview`.

## Арт: куда класть файлы

Кладите PNG в `public/assets/` под нужным именем и обновите страницу: картинка заменит заглушку. Код менять не нужно. Если файла нет, игра рисует заглушку (её подпись показывает, какой файл ожидается). Список недостающих файлов выводится в консоль браузера (F12) строкой `[assets] заглушки`.

| Что | Путь (от `public/assets/`) | Размер |
| --- | --- | --- |
| Людьмак | `portraits/hero/ludmak.png` | 512×640 |
| Враги | `portraits/enemies/{id}.png` | 512×640 |
| Заказчики | `portraits/clients/{id}.png` | 512×640 |
| Предметы героя | `items/{id}.png` | 128 px на клетку: 1×1 → 128×128, 1×3 → 128×384, 2×2 → 256×256 |
| Предметы врагов | `items/enemy/{id}.png` | 128 px на клетку, формы — в таблице ниже |
| Значки тегов | `tags/{id}.png` | 64×64 (можно больше, квадрат) |
| Дом Людьмака | `backgrounds/home.png` | 1920×1080, интерьер избы с дверью (см. ниже) |
| Фоны | `backgrounds/bg_night.png`, `backgrounds/bg_battle.png` | 1920×1080 |
| Лошадь под рюкзаком | `backgrounds/horse.webp` | 1421×1107, с прозрачностью; привязка к клеткам — `HORSE_ART` в config/assets.ts (147 px на клетку) |

### Дом Людьмака (`home.png`)

Вид изнутри избы: в центре дверь с окошком-задвижкой, слева доска на стене и сундук/прилавок, справа седельные сумки на крюке. Игра рисует поверх фона только карточку заказа, доску, подписи и портрет в окошке. Сами дверь, сундук и сумки должны быть на рисунке.

Где на рисунке дверь, окошко, сундук, сумки, доска и карточка, задаёт `HOME_LAYOUT` в `src/config/assets.ts`: прямоугольники в координатах 1920×1080. Если на рисунке всё стоит иначе, поправьте числа там, код менять не нужно. Окошко — скруглённый прямоугольник (`window`: x, y, w, h, radius), портрет заказчика обрезается по нему. Размер и сдвиг портрета в окошке задают `portraitWidth` и `portraitOffsetY`. Заглушка `home.png` нарисована по этим же числам, так что видно, куда что попадает.

## Звуки: куда класть файлы

Принцип тот же, что у арта. Кладите файл в `public/assets/audio/` под именем ключа и обновите страницу — звук заиграет, код менять не нужно.

- Формат: `{ключ}.ogg`. Если `.ogg` нет, игра ищет `{ключ}.mp3`.
- Нет ни того, ни другого — звук молча пропускается. Список недостающих выводится в консоль браузера (F12) строкой `[audio] нет файлов`.
- **Громкость** — в `src/config/volume.ts`: общая для звуков и музыки (`SFX_MASTER`, `MUSIC_MASTER`) и отдельно для каждого звука и мелодии (`SOUND_VOLUME`, `MUSIC_VOLUME`, шкала 0..1). Лимит одновременных копий одного звука и длительность смены музыки — в `src/config/audio.ts` (`AUDIO`).
- Кнопка «Без звука» есть в верхней панели (и в меню). Вверху меню — ползунок общей громкости (звуки и музыка вместе, поверх `volume.ts`). Оба выбора запоминаются в браузере.

**Музыка** (по кругу, плавная смена между сценами):

| Ключ | Где играет |
| --- | --- |
| `music_night` | меню, дом, магазин, рюкзак, итоги, конец игры |
